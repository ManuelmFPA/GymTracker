# Frontend (FASE 3) — Pagina Gym

Scaffold mínimo React + Vite + TypeScript + Tailwind.

Instalación y ejecución:

```bash
cd frontend
npm install
npm run dev
```

Variables útiles:
- `VITE_API_URL` — URL base del backend (por defecto `http://localhost:8080`).

Rutas implementadas:
- `/login` — iniciar sesión
- `/register` — crear cuenta
- `/exercises` — listar ejercicios (GET `/exercises`)
